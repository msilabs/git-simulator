# Code of Conduct

This project exists to help new developers learn Git without fear. Please keep every interaction welcoming, especially toward beginners.

## Our standards

- Be kind and patient. No question is too basic here.
- Give feedback about code and ideas, never about people.
- Write in Bengali or English, whichever is easier for you.
- Do not harass, insult or demean anyone, and do not post others' private information.
- Do not post sexualized content, or attack anyone over gender, religion, ethnicity, disability or any other part of who they are.

## Enforcement

Maintainers may edit or remove comments, commits, issues and pull requests that break these rules, and may block repeat offenders.

To report a problem, contact the maintainers privately (msisaif on GitHub) or open an issue if it is not sensitive. Reports are kept confidential.

This code of conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.
